# 💪 健身计划 FitPlan

一个**纯前端的移动端健身计划工具**，单文件 HTML、零后端、可装到手机桌面。所有数据保存在浏览器本地（`localStorage`），不依赖任何服务器。

---

## ✨ 功能模块

| 模块 | 说明 |
| --- | --- |
| 📅 每日训练计划 | 一周 7 天计划，动作卡片含图标、组数、次数、部位、器械；顶部汇总卡显示训练重点、约耗千卡、总组数、主要/次要肌群 |
| 📚 动作指导库 | 40+ 动作，每个含「动作要领」+「注意事项」+ 肌肉示意图；点卡片展开，或进全屏指导页分组打卡 |
| 🔥 练前热身 | 肩部绕环 / 猫式伸展 / 髋关节绕环 / 腿部摆动，固定在计划页顶部 |
| ✅ 训练打卡 + 计时器 | 组数打卡（set-chip）、动作计时、完成标记；悬浮按钮支持休息倒计时 30/60/90/120s 与正计时秒表 |
| ✏️ 自定义计划 | 编辑模式增删动作、改组数次数要点、设为休息日、图标选择器、一键恢复默认；损坏数据自动修复 |
| 🏋️ 训练计划库 | 3 套预设：新手全身循环 / 健身房三分化（推拉腿）/ 哑铃居家三分化；支持详情查看、一键应用、文本分享 |
| 🎯 专属计划生成器 | 按「目标 × 场地 × 每周天数 × 水平」自动生成计划，减脂目标自动附带有氧 |
| 🍱 饮食记录 | 按日记录食物、份量、备注；近 14 天趋势 |
| 🥗 食物素材库 | 41 种常见食物分 7 类，含热量/蛋白质/快捷份量；支持搜索、分类、数量选择、自定义食物 |
| ⏱️ 轻断食 | 16:8 / 18:6 / 20:4 方案，实时倒计时 + 进度条 |
| 📷 拍照识别热量 | 拍照经视觉模型识别食物与热量，可编辑后批量入今日饮食；需配置 AI Key |
| 🥦 营养师分析 | 规则引擎按目标热量/蛋白质进度、蔬菜/零食/断食情况给出建议 |
| 🔔 训练提醒 | Notification API 定时弹通知，到点提醒训练 |
| 📊 身体记录 | 体重录入、近 14 次趋势图、饮水 8 杯打卡 |
| 📈 统计 | 本周进度环、训练完成统计、训练记录、数据导出/清空 |
| ⚙️ 我的 / 设置 | AI 识别配置、提醒开关与时间、主题、数据管理、版本号标识 |
| 📱 PWA 安装 | 可「添加到主屏幕」全屏运行，像 App 一样离线使用 |

## 🛠️ 技术栈

| 分类 | 说明 |
| --- | --- |
| 前端语言 | 原生 HTML + CSS + JavaScript（ES6），无框架、无编译 |
| 架构形态 | 单文件 PWA，133KB `index.html` 内联全部 CSS/JS |
| 数据存储 | `localStorage`（按「本周一日期」为 key） |
| PWA | `manifest.json` + SVG/PNG 图标，可安装、可全屏、可离线 |
| AI 能力 | OpenAI 兼容视觉 API（默认智谱 `glm-4v-flash`），仅拍照识别热量使用 |
| 图表 | 原生 SVG（趋势图 / 进度环 / 肌肉示意图），无图表库 |
| 第三方依赖 | 0 个运行时依赖 |
| 本地调试 | Python `http.server` 自定义服务，端口 8791，已禁用缓存 |

## 📦 部署说明

### GitHub Pages
1. 仓库：`Zds200409/fitness-plan`（公开）
2. 上传 `index.html`、`manifest.json`、`icon.svg`、`icon-192.png`、`icon-512.png` 到**仓库根目录**
3. `Settings → Pages → Source` 选 `main` 分支 `/root`

## ❓ 常见问题

**Q：更新后手机上还是旧的？**
A：先强制刷新或清浏览器缓存；已添加到桌面的无需重新添加，首次打开会拉取新版。

**Q：拍照识别没反应？**
A：需在「我的」页配置 AI Key（默认智谱 `glm-4v-flash`）。

**Q：数据会丢吗？**
A：数据存在本机浏览器 `localStorage`，清缓存/换设备会丢失；重要数据可用「统计」页导出备份。

**Q：换手机能同步数据吗？**
A：不能（纯前端无后端），同一台手机同一个浏览器内数据互通。
